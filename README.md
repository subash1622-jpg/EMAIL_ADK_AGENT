# 📧 Gmail API Email Sender

A simple Python project to send emails securely using the Gmail API and OAuth 2.0 authentication.

## Features
- Gmail API integration
- OAuth 2.0 authentication
- Send emails from Python

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
